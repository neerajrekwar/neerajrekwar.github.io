## ⚡ Features

- **Architectural Geometric Design**: Stark 2px borders, high-contrast layouts, and clean brutalist aesthetics.
- **Projects Showcase**: Interactive carousel and modal previews for featured applications (WalkTrip, NewslyUSA).
- **Open-Source Package Registry**: Dedicated showcase for custom npm packages with quick-copy install snippets.
- **AI Dev-Pitch Generator**: Client-safe interactive pitch engine illustrating technical focus areas.
- **Static Export & GitHub Pages**: Fully static build (`output: 'export'`) optimized with SEO metadata, `.nojekyll`, `robots.txt`, and `sitemap.xml`.
- **Automated CI/CD**: Automatic builds and deployments via GitHub Actions on push to `neerajrekwar` or `main`.

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/neerajrekwar/dgfsfd.git

# Navigate into project directory
cd dgfsfd

# Install dependencies
npm install
```

### Local Development

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the site locally.

### Production Build & Export

```bash
# Typecheck
npm run typecheck

# Build and export static assets to ./out
npm run build
```

## 🌐 Environment Configuration

The project uses `.env.production` for build-time environment variables:

```env
NEXT_PUBLIC_SITE_URL=https://neerajrekwar.github.io
NEXT_PUBLIC_BASE_PATH=
```
